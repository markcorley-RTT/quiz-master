# Quiz Master

Pass-the-question trivia. The Quiz Master scores most when about half the room gets it right.

## Setup
1. Create a Firebase project, enable Firestore, add a Web app.
2. Paste the `firebaseConfig` values into `firebase-config.js`.
3. In Firestore → Rules, paste the contents of `firestore.rules` and publish.
4. Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Players open the site URL (optionally with `#CODE` on the end) in any phone browser. No accounts needed.
